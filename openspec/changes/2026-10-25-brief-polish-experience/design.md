# Context
确定性 context-brief/0.1 是正式基线。模型不能提供事实确认依据。

# Goals / Non-Goals
目标：显式启用的文字候选、可核对导出、可恢复编辑体验。非目标：自动润色、自动确认、持久化候选、引入队列或新数据库。

# Decisions
服务端启动参数配置可信模型端点，未配置时不发请求。每次润色需 consent=true 和用户看到的 snapshot_id。服务端自行按原请求构建简报，不接受客户端原话。模型调用前后重建校验快照，发生修订/遗忘则拒绝输出。只接受原条目引用集合，输出始终 proposed，与原简报分开展示。网络超时、大小和重定向均受限；错误不携带响应正文。默认导出只包含确定性结果，转义不可信 Markdown，保留来源和状态。复制/外发内容无法由永久遗忘撤回。

# Risks / Trade-offs
结构校验不能证明模型文字真实，因此候选始终需要人工核对。显式调用可能向配置的外部服务发送范围内内容，界面事先说明。已有返回内容仍是快照，不能承诺撤回外部副本。

# Migration Plan
无需迁移；不配置新参数即维持默认行为。

# Open Questions
无。

复用 Pi 的 models.json 通过显式 CLI 参数选择 provider/model，默认路径仅在启用时解析。不支持命令式 apiKey，不执行配置中的脚本；只加载所选模型的端点和密钥。沿用 HTTPPolisher 的 HTTPS/loopback、大小和超时限制。local-start 仅向 Web 传递相应参数，不自动开启 worker 生成。
